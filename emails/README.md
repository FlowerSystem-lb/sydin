# SydIN auth emails

Generated by `node emails/build.mjs` — edit that file, not the templates.

In Supabase: **Authentication → Emails → Templates**. For each row, open the
template, set the **Subject**, paste the whole file into **Message body**, Save.

| Supabase template | Subject | File |
|---|---|---|
| Confirm sign up | `{{ .Token }} is your SydIN verification code` | templates/01-confirm-signup.html |
| Reset password | `{{ .Token }} is your SydIN password reset code` | templates/02-reset-password.html |
| Magic link | `{{ .Token }} is your SydIN sign-in code` | templates/03-magic-link.html |
| Change email address | `{{ .Token }} confirms your new SydIN email` | templates/04-change-email.html |
| Reauthentication | `{{ .Token }} is your SydIN security code` | templates/05-reauthentication.html |
| Security notifications > Password changed | `Your SydIN password was changed` | templates/06-alert-password-changed.html |
| Security notifications > Email address changed | `Your SydIN email was changed` | templates/07-alert-email-changed.html |
| Security notifications > Identity linked | `A new sign-in method was added to your SydIN account` | templates/08-alert-identity-linked.html |
| Security notifications > Identity unlinked | `A sign-in method was removed from your SydIN account` | templates/09-alert-identity-unlinked.html |

Security notifications (06–09) must also be switched **on** in the same page.
The code emails expect **Email OTP Length = 6** (Authentication → Providers →
Email) — the app's code boxes are six digits.
